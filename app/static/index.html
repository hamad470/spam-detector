SMS Spam Detector

Paste a message and the model returns a spam probability, plus the words that drove the decision.

GitHub API docs
Try:
hamthreshold 0.5spam

Why

    Red words push towards spam and green words towards ham. Weights are the Naive Bayes log-likelihood ratio for each word's stem.
